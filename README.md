# Maksym Bardakh

Founder and CEO of [BBMM Technologies](https://bbmmtech.com), a small product studio in Halifax, Canada. We build apps for Apple platforms and mobile, plus the occasional piece of hardware when software alone can't fix the problem.

## Products

- **[Flowo](https://flowoapp.com)**: software for neurodivergent people that automates daily planning and provides support when plans change. iOS and Android, built in Flutter on a FastAPI backend.
- **[TextPack Pro](https://textpack.app)**: a Mac app that turns plain text and Markdown into clean PDFs. SwiftUI and PDFKit.
- **Pillow**: thought capture for macOS, iOS and watchOS. In development.

## Open source

## Stack

Swift and SwiftUI. Flutter and Dart. Rust and Tauri. Python with FastAPI. TypeScript with React and Next.js. C on ESP-IDF. AWS for infrastructure.
